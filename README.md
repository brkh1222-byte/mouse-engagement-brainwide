# mouse-engagement-brainwide

Where in the brain is "zoning out"? This repo maps brain-wide pre-stimulus signatures of latent engagement states in the IBL Brain-Wide Map, with a replication in Steinmetz et al. (2019).

📄 **Read the research proposal:** [PROPOSAL.md](PROPOSAL.md) · **Tasks:** [TASKS.md](TASKS.md)

## Plan

GLM-HMM engagement states from behaviour → pre-registration → pre-stimulus spike counts per region → decoding with block-prior and movement controls → brain map → cross-lab replication
